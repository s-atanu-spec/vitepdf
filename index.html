Tools

What it does

Right-click one or more files, or the empty space in a folder, and choose VitePDF. Results are saved next to the original, under a new name.

Sizes

Fit an upload limit

Under 1 MB, 350 KB, 200 KB, or a size you type. VitePDF keeps the best quality that fits and tells you if a target cannot be reached.

Pictures

Pictures to PDF

JPG, PNG, HEIC, WEBP and BMP. Pages keep the exact shape of the picture: no stretching, no margins. "Original" stores it without any loss.

Both

Merge anything

Select pictures and PDFs together, set the page order in one window, pick the result size, and get one PDF.

PDF

Pages and passwords

Reorder, remove, rotate, crop and split pages. Add a password, or save an unlocked copy of a PDF whose password you know.

Clean-up

Remove hidden data

A copy without camera and location data, author details, scripts or attachments. The saved copy is checked again afterwards.

Folder

New blank PDF

Right-click the empty space in a folder for an empty PDF in the paper size, direction and number of pages you choose.

Capture

Two ways to capture your screen as a PDF

Both work over a browser page or any other program, and both keep the sharpness of your screen.

VitePDF Capture

Ctrl Alt Shift P

For what you can see at once. The screen dims, you drag a box, and that area is saved as a PDF.

  • Start it from the Start menu, the taskbar once pinned, or the keys.
  • The first time, choose where captures go: Downloads, Desktop, or your own folder.
  • Inside a folder, right-click the empty space and choose Capture area to PDF.

VitePDF Scroll

Ctrl Alt Shift S

For a page longer than your screen, such as a long email. You draw a box and the page scrolls by itself.

  • Everything that passes through the box is joined into one PDF.
  • Touch the mouse to take over, then drag the red END line to the last line you want.
  • A preview shows the number of pages before you save.

Getting started

How it works

No window to open first, no account, no upload.

Install once

Run the Setup file. It adds VitePDF to the right-click menu for your Windows account only.

Right-click a file

Choose VitePDF and the tool you need. Select several files to handle them in one go.

Use the result

The new file appears beside the original. VitePDF stays silent unless there is something you need to know.

Privacy

Private by design

VitePDF was built for documents you would not want to hand to a website.

What it never does

  • It never connects to the internet. The program contains no network code.
  • It never uploads, collects or reports anything.
  • It never changes or replaces your original files.
  • It never asks for admin rights.

Check your download

Every release is signed by the author. The key fingerprint is:

A88B A544 E686 3A3C 1877 0B0C 3C40 DEBC

The release page explains how to check a download against it. Windows may show a blue "Windows protected your PC" box, because the file has no paid publisher certificate: choose More info, then Run anyway.

Open source under the MIT licence. The security notes, including the limits the author accepted, are in SECURITY.md. Always check a result before you use it.
